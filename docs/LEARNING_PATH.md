# Learning path — Starter → Advanced

| Level | Focus | Surfaces |
|-------|--------|----------|
| **Starter** | Orientation + First hour | Lab orientation, checklist |
| **Beginner** | Lab core + quiz | Lab, path, passphrase compare, quiz |
| **Intermediate** | Three splits + entropy/PSBT | Multisig, Shamir, SLIP-39, Tools entropy/PSBT, tour |
| **Advanced** | BIP-85 idea + private ops | BIP-85 card, Ops/Knots card |

Level is a **soft gate** (`localStorage bip39lab.level`), not authentication.

## Private ops (Advanced)

- Pi / Knots: `docs/BITCOIN_KNOTS.md`  
- Seed scan CLI: `scripts/seed_scan_educational.py`  
- No public website seed scanner
