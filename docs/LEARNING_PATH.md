# Learning path — Starter → Advanced

| Level | Focus | Surfaces |
|-------|--------|----------|
| **Starter** | Orientation + First hour | Lab orientation, checklist |
| **Beginner** | Lab core + quiz | Lab, path, passphrase compare, quiz |
| **Intermediate** | Three splits + Tools depth | Tour + **I1–I4** (keys vs shares vs words + PSBT inspect-only); Multisig/Shamir/SLIP-39/Tools |
| **Advanced** | Ops mind offline | BIP-85 + Ops + **A1–A4** (BIP-85 idea, watch-only, Knots limits, is-not) |

Level is a **soft gate** (`localStorage bip39lab.level`), not authentication.

Progress keys (browser only): `bip39lab.firstHour`, `bip39lab.quiz`, `bip39lab.intQuiz`, `bip39lab.advQuiz`.
