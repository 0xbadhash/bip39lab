What this page is

Public fees and address-only balances — not your seed. Failures stay unknown (no fake zeros).

Privacy: looking up an address tells the API host you care about it (like typing an account number into a public search box). Lab stays offline for secrets.

Is / is not

Is: fee snapshot, mempool traffic, optional address balances.
Is not: a wallet, price charts, or spending tools.

Fees & traffic Fee rate (sat/vB) is like postage for Bitcoin transactions — higher often confirms faster when busy. Example cost assumes ~140 vB (simple modern send) — estimate only.
