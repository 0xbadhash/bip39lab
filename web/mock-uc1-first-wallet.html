What is a recovery phrase?

Seed / phrase = the secret. Anyone with these words can move coins in a real wallet. Here it is practice only.

What is a receive address?

Address = a public number people pay. Safe to share. It is not the phrase.

Why many addresses?

Same phrase → many addresses (index 0,1,2…). All still need the same backup.
