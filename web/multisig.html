Offline

What is multisig?

Think of a bank safe-deposit box that needs more than one key. A normal Bitcoin address is 1-of-1: one private key can spend. Multisig means M of N keys must agree before coins can move.

  • N — total keys (cosigners), like N officers who each hold a key.
  • M — how many must sign a payment (e.g. 2-of-3: any two of three).
  • Public key — safe to share for building the vault address (like a lock blueprint).
  • Private key — never paste here; this page refuses WIF / xprv (safety).

What this tool is: an offline calculator that turns M + public keys into a shared receive address and the script that defines the vault.
What it is not: a wallet, a transaction signer, or a blockchain scanner. It will not broadcast anything or “discover” funded combos on explorers (that would hurt privacy).

Build an address (public keys only)

Paste compressed public keys as hex (66 characters, start with 02 or 03), one per line. Get cosigner pubkeys from hardware wallets / Sparrow — not private keys.

How many signatures are needed to spend (like “2 directors must approve”).

When on, keys are sorted the same way for everyone so you all get the same address. Leave on unless you know you need a fixed custom order.
