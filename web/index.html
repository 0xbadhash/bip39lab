Address balance (CLI)

            

              This page never loads balances (CSP blocks network). Use the CLI so seed material never leaves your machine
              for a balance check. Public explorers only see the address after you opt in.
            

            
Free public review (no Bitcoin Core required) — mempool.space REST:

            
python -m bip39lab balance bc1q… \
  --backend mempool \
  --i-understand-address-leak

            
Your own node (preferred when available):

            
python -m bip39lab balance bc1q… \
  --backend bitcoind \
  --rpc-cookie ~/.bitcoin/.cookie

            

              There is no free public Bitcoin Core JSON-RPC for everyone on the Internet.
              Free checks use explorer REST; real JSON-RPC is your node.
