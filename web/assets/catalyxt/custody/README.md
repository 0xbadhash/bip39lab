# Catalyxt custody kit (bip39 tracks)

Not the exam **Gap kit** (plan / timed mock / Yes).  
These shapes teach **custody objects**. Consume from `/v2/` as  
`../assets/catalyxt/custody/…`

## Sizes

| Slot | ViewBox | Caption | Use |
|------|---------|---------|-----|
| **A · chapter** | `0 0 96 48` | none | Sidebar / chapter strip. Hairline. |
| **B · track atom** | `0 0 220 88` | **under**, not inside. Drawing `y=8–66`. Caption `y=80`, 8–9px, muted. 8px inset. | V2 Plan / Practice / Review atoms. |

Do not mix: no caption in slot A; no full-bleed drawing into the caption band in slot B.

## Two languages (both official)

| Language | Where | Rule |
|----------|--------|------|
| **Hairline** | `hairline/*.svg` | `fill="none"` `stroke="currentColor"` `stroke-width="1"`. 4px grid. Theme-safe. |
| **Panel** | `atom/*.svg` | Filled `#1a2330` panels. Dark V2 only. Semantic strokes below. |

Chapter compositions stay hairline. V2 track atoms stay panel.

## Semantic strokes (pictures, same as chips)

| Role | Hex (dark) | Meaning |
|------|-----------|---------|
| **accent** | `#3d8bfd` | Structure, the object in play |
| **ok** | `#22a06b` | Survives / allowed |
| **bad** | `#e2483d` | Reject |
| **muted** | `#8b9bb4` | Caption, inactive |
| **idle** | `#2a3545` | Unused cell / unused key |

## Photoreal

**Forbidden in V2 tracks.** No generated photos, no fake “RECOVERY CODE” grids.  
Classic Lab **3D faces** (key / dice / lock) stay on `/` stills only. Do not add new photoreal atoms.

## Hands

Allowed **only** as `hand-pen.svg` (geometric). No photos of hands.
