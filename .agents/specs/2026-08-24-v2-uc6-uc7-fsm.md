## Problem

UC6 did not teach M-of-N on the demo pad. “Make 3 throwaway xpubs” hid three independent seeds and printed BIP-84 **zpub** while the button said xpub. Quizzes said “Not that one.” The rail could not go back. UC7 led with a Shamir **room** link as if it were a stray tab.

## Solution

- UC6 pad 0 = M-of-N spend policy (2-of-3 picture).
- UC6 pad 1 = three visible cosigner phrases (word count, generate, zpub, clear this / clear all). Default export **BIP-84 zpub** (SLIP-132). Label it zpub, not “xpub.”
- UC7 stays Shamir: in-track split first; room is a footer deep link with why.
- Every quiz **bad** click shows a specific **why**.
- Step **rail** jumps to any visited step (`maxStep`). Concept chips jump only to a mapped **visited** step.

## FSM (all V2 tracks)

```
PICKER --uc--> GATE --Start--> STEP 0
STEP n --Pause (enabled)--> STEP n+1   [maxStep = max(maxStep, n+1)]
STEP n --rail click i<=maxStep--> STEP i
STEP n --concept chip (mapped j<=maxStep)--> STEP j
QUIZ --wrong--> stay, show why, Pause stays disabled
QUIZ --right--> Pause enabled
FINISH --force ack--> PICKER (track done)
Clear secrets (UC1/2) --> STEP 0 same track
Clear secrets (UC6 cosigners) --> wipe A/B/C, stay on Three cosigners
Clear secrets (other) --> PICKER
Never jump to unvisited steps. Never mix UC6 keys with UC7 shares on one pad.
```
