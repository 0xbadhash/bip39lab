## Problem Statement

UC8 inspect only had three historical payment txs. Operator asked for 2–3 real txs that carry **on-chain data**: OP_RETURN ASCII, an ordinal inscription, a Runestone. Classroom snapshots must still work when proxy + mempool.space abort. Teach vs result stays: story in `#v2TxStory`, decoded bytes in `#v2PsbtNetLive`.

## Solution

- `PSBT_EX_TX` grows from 3 to 6 named rows:
  - OP_RETURN note `8bae12b5…` block 308570 — ASCII “charley loves heidi”
  - Inscription 0 `6fb976ab…` block 767430 — witness `ord` + `image/png`
  - Runestone etch `f03cba9c…` block 840000 — `OP_RETURN OP_13` UNCOMMON•GOODS•ARE•NOT•RARE
- `opReturnNotes` / `witnessNotes` decode live JSON and classroom snaps (`scriptpubkey_asm`, `vin[].witness`, `inner_witnessscript_asm`). MIME hex that looks like `text|image|application/` is printed.
- Live fetch still `/api/mempool` then `https://mempool.space/api` after leak-ack. Snap if both miss.
- No Sign. Practice inspect only. Do not mint runes or inscribe.

Chip `v0.17.126-v2`. Product stamp on ship.
