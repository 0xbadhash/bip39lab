## Problem Statement

Classic Lab has `#mnemonic` paste and `#card-addresses` tabs BIP44 / 49 / 84 / 86. V2 UC1 only generates a phrase and shows BIP84 receive rows. Leftover in `web/v2/compare.md`: paste mnemonic + full 44/49/84/86 matrix.

## Solution

Port those two jobs into **existing UC1 steps**. Do not add tracks. Do not add a signer. Do not broadcast.

1. **Paste.** UC1 step 0 keeps Make practice words. Add `#v2PasteMn` + `#v2PasteApply`. Valid English BIP-39 (12–24) loads the numbered card the same as generate. Invalid paste does not load words. Practice only — do not import a funded phrase.
2. **Address types.** After Show receive addresses, `#v2AddrType` tabs BIP86 / BIP84 / BIP49 / BIP44 switch the field painted from the same `deriveAddresses` rows (`bip86_p2tr`, `bip84_p2wpkh`, `bip49_p2sh_p2wpkh`, `bip44_p2pkh`). Default remains BIP84 so existing tb1q/bc1q checks hold. Copy + QR stay on the visible column. One type at a time, same as classic.

Chip `v0.17.90-v2`. Product stamp only on ship. No Imagine. No photoreal.
