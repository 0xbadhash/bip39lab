# Shamir secret sharing — new left-nav tab (v1 teach + demo split)

- **Created:** 2026-08-07

- **Priority:** P1
- **Roadmap:** `ROADMAP.md` → Open work (**Next**)

## Problem Statement

Learners hear “split your seed with Shamir” without a safe place to **see** what that means. Multisig already teaches M-of-N for *keys*; there is no first-class surface for M-of-N for *shares of a secret*. Users should not paste a real recovery phrase into an experimental splitter until they understand the concept and the product marks it as educational.

## Solution

A new **Shamir** item on the **left sidebar** (step **3**, after Multisig) opens a dedicated offline page that:

1. Explains Shamir secret sharing in plain English (threshold, shares, what is *not* BIP-39 words).
2. Runs a **demo-only split**: user picks **M-of-N**, supplies or generates a **throwaway practice secret** (never auto-using Lab’s live mnemonic without an explicit dangerous opt-in — default is generate-demo or paste practice text).
3. Shows **N share cards** (copyable, labeled Share 1…N) and states clearly that recombining is **out of scope for v1** (or “coming later”).
4. Never phones home; CSP matches Lab/Multisig offline crypto; no retention of secrets.

## User Stories

1. As a learner, I open **Shamir** from the left nav so I can study share-based backup without leaving the lab shell.
2. As a learner, I read a short teach block (what Shamir is, M-of-N, difference from Multisig and from BIP-39 wordlists) so I do not confuse concepts.
3. As a learner, I set **M** and **N** (with safe defaults, e.g. 2-of-3) and click **Split demo** so I see N labeled shares appear offline.
4. As a learner, I can **Generate practice secret** (random hex or short demo string) so I never need a real seed for the demo.
5. As a learner, I can copy one share for clipboard practice on an air-gapped machine, knowing the page warns this is educational.
6. As a cautious user, I am **blocked or strongly warned** if I try to treat this as production SLIP-39 / Trezor recovery (v1 is **not** SLIP-39-compatible).
7. As a returning user, I see consistent **5→6 nav** labels on Lab, Multisig, Network, Tools, Glossary, and Shamir pages.

## Implementation Decisions

- **Surface:** New page `web/shamir.html` (or equivalent) + shared sidebar nav on all pages; step numbers renumbered (Shamir = 3, Network = 4, Tools = 5, Glossary = 6).
- **Crypto stance (v1):** Educational Shamir over a **byte secret** (practice string / generated bytes), **not** SLIP-39 wordlists, **not** Trezor-compatible shares. Label UI **“Educational Shamir (not SLIP-39)”**.
- **Default secret source:** Generate practice secret on page; optional paste field for practice text; **do not** silently pull Lab mnemonic. Optional later: “Use Lab phrase” behind explicit danger confirm + teach-off safety — **out of scope unless tiny**; prefer out of scope for v1.
- **Offline:** `connect-src 'none'` on Shamir page (same class as Lab/Multisig).
- **No network, no retention:** same AGENTS non-negotiables.
- **Glossary:** Add/link Shamir / threshold / share terms.

## Testing Decisions

- **Seam:** Pure function(s) `splitSecret(secretBytes, m, n) → shares[]` with unit tests (known toy vectors if we implement finite-field SSS; or property: any M shares reconstruct when recombine exists — recombine may be internal test-only in v1 without UI).
- **E2E:** Playwright shell: nav count 6, Shamir active, CSP offline, split produces N cards, danger copy visible.
- **Smoke:** product `smoke[]` (pytest + e2e) green; Comet doc updated for Shamir surface.
- **Manual:** Open Shamir on local static server; 2-of-3 split; no network in DevTools.

## Acceptance Criteria

- [ ] Left nav includes **Shamir** as step **3** (after Multisig) on **all** primary pages (Lab, Multisig, Shamir, Network, Tools, Glossary surfaces).
- [ ] Opening Shamir shows teach copy: Shamir vs Multisig vs BIP-39; banner **educational / not SLIP-39 / not for real funds**.
- [ ] User can set M and N with validation (`2 ≤ M ≤ N ≤` sensible max, e.g. N≤5 or 7 for demo).
- [ ] **Generate practice secret** + **Split demo** yields exactly N labeled share blobs offline (copy buttons work).
- [ ] Empty/invalid M,N or empty secret → clear error; no fake success.
- [ ] Page CSP is offline crypto (`connect-src 'none'`); no mempool/RPC.
- [ ] No automatic use of Lab mnemonic; no server retention.
- [ ] Playwright: nav parity + Shamir smoke scenario(s); unit tests for split math/API.
- [ ] Product smoke commands succeed; Comet/e2e docs mention Shamir; no secrets committed.
- [ ] Glossary entry for Shamir (or threshold secret sharing) reachable from teach tips.

## Out of Scope

- **SLIP-39** / Trezor wordlist compatibility and recovery onto hardware.
- **Recombine UI** (full recover-from-shares flow) — deferred to a follow-up ship (test-only recombine OK).
- Production backup of **real** funded seeds (product remains educational lab).
- Network, fees, balances, or Knots integration on this page.
- Multisig policy changes; SeedQR / animated QR of shares.
- Non-English UI.

## Further Notes

- **Constitution:** Offline-first + no retention apply. Teaching SSS can encourage dangerous DIY seed splitting — copy must stress **demo only** and prefer hardware / audited SLIP-39 products for real funds.
- **Confusion risk:** Multisig = M-of-N *keys*; Shamir = M-of-N *shares of one secret*. Explicit compare table on page.
- **Nav churn:** v0.12.3 reduced to 5-nav; this ship expands to **6-nav** again with a real feature (not docs-only).
- **Risk:** Hand-rolled SSS bugs → mitigate with unit tests + “educational” labeling; prefer a small audited pure implementation or well-tested GF(256) toy with clear limits.
